Cara Meng-Online-kan CBT TKA Menjadi Link HTTPS Gratis

Aplikasi ini dirancang dalam 1 file HTML mandiri sehingga dapat langsung dijadikan alamat web berprotokol aman HTTPS tanpa perlu menyewa server mahal.

Cara 1 (Tercepat • 1 Menit) HTTPS Otomatis

Netlify Drop (Drag & Drop)

  1. Klik tombol Download File index.html Siap Upload di kanan atas, masukkan ke dalam satu folder baru (misal folder cbt-tka).
  2. Buka situs app.netlify.com/drop di browser dan login gratis.
  3. Tarik (drag & drop) folder cbt-tka ke halaman Netlify.
  4. Dalam 10 detik Anda langsung mendapatkan link https://nama-ujian.netlify.app yang siap dibagikan ke HP/Laptop siswa!
Cara 2 (Permanen) HTTPS Gratis

GitHub Pages

  1. Buat akun gratis di github.com dan buat Repository baru bernama cbt-nurussalam.
  2. Upload file index.html ke repository tersebut.
  3. Masuk ke menu Settings → Pages, pilih branch main lalu klik Save.
  4. Akses ujian melalui https://username.github.io/cbt-nurussalam.
Cara 3 (Cepat & Ringan) HTTPS Global CDN

Vercel Hosting

  1. Buka vercel.com dan masuk menggunakan akun Google/GitHub.
  2. Pilih Add New Project atau unggah folder berisi index.html.
  3. Vercel otomatis memberikan sertifikat SSL HTTPS aktif dan performa server super cepat untuk ratusan siswa sekaligus.
